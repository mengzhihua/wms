# WMS 亮点

WMS 按仓储执行来做：收货上架、分配拣货发运、库内作业，库存账记到仓库、库位、货主、物料和批次。

1. **分配按效期和收货时间，而不是随便扣一笔库存。** 先 FEFO 再 FIFO，只从存储位和拣货位出，不够就部分分配，之后还能再分。
2. **波次把多单合成一次总拣，再按单播种。** 八种预置策略按优先级自动成波或拆波，也可以先预览。少拣会把缺口释放回去。
3. **越库不用先上架再拣出来。** ASN 绑出库单后，收货直接分到发货暂存，超出需求的数量仍走正常上架。
4. **盘点是计划，不是一张临时表。** 审批后按库存锁库，领取、复盘、调整单审核过账，锁未释放前不能拿去分配。
5. **补货分仓内和跨仓。** 拣货位低于安全库存时从存储位补到最大库存；源仓和目标仓不同时走调拨，扣源仓可用量并加到目标仓拣货位。
6. **序列号、箱型和包材跟作业走。** 受控物料收货和发运都要扫号；打包按体积重量推荐箱型，并扣包材库存。
7. **控制塔按单号分配、按仓补货。** 开放接口带幂等键，重复下发不会再分配一次或再生成一张补货任务。
